# 旺财本机加密与隐私说明

## 已实现的保护

- 主账本以 `wangcai-vault-v1` 密封包保存，不再把可读 JSON 直接写入 `localStorage`。
- 每份账本生成随机 256 位数据密钥；设置口令经 PBKDF2-HMAC-SHA-256（600,000 次迭代）派生保护密钥，用于加密包裹数据密钥。
- 账本内容与数据密钥包裹值分别用 AES-256-GCM 加密；每次保存产生新的 96 位随机 nonce，并使用固定用途标签作为附加认证数据。
- 不保存用户口令或明文数据密钥。解锁后密钥只在本次应用会话内存中使用；为支持用户主动轮换口令/恢复密钥，内存中的 CryptoKey 可由加密模块导出并立即重新包裹，导出的临时字节会清零，不写入持久存储。“立即锁定账本”会先完成密文保存，再清空界面状态和密钥引用。
- 首次运行需创建至少 12 字符的口令。旧版明文账本迁移时，先写入密封包并实际解密校验，成功后才删除旧键；失败时保留旧数据，不回退到明文保存。
- `.wangcai` 备份保存加密密封包和工作证据附件的密文。恢复前需要口令或恢复密钥，认证成功后再确认覆盖；错误凭证或密文被改动时不会覆盖本机账本。
- 新建账本时额外生成一把 256 位随机恢复密钥，并用它独立包裹同一数据密钥。恢复密钥只在生成时显示；忘记口令可用它解锁、设置新口令并轮换恢复密钥。旧版账本解锁后可在“设置 → 本机加密与锁定”中生成。
- CSV/XLSX 导出前显示明文风险确认。节假日数据改为用户主动联网更新，启动时只读取内置或本机缓存数据。
- 工作证据原件逐份使用同一账本数据密钥、独立随机 nonce 和 AES-GCM 加密，密文存放于本机 IndexedDB；账本内仅保存文件元数据、SHA-256 和用户操作时间线。打卡编辑、删除、批量清空和导入会追加哈希链事件。导出或恢复前核对时间线与原件哈希。

## 本机加密如何工作

`localStorage` 本身并不替应用加密。旺财先把账本对象编码为 JSON 字节，再通过 Web Crypto API 用 AES-GCM 加密，最后只把算法版本、随机盐、nonce、被口令保护的数据密钥和账本密文写进本机存储。解锁时反向派生保护密钥、打开数据密钥包裹、验证认证标签并解密。任何字段被意外改动时，认证校验会失败。

每份数据密钥由安全随机数生成，口令从不作为 AES 密钥直接使用。每次加密都生成新 nonce；盐与 nonce 不需要保密，但必须随密文保存。口令和派生密钥不会写入存储、日志或导出备份。

## 迁移与恢复

首次启动分为三种状态：新账本显示“开启加密”；检测到旧版 `dagong-ledger-v1` 明文时显示迁移说明；检测到密封包时显示解锁页面。损坏、口令错误、Web Crypto 不可用或存储写入失败都不会将账本重置为空并自动保存。

同一浏览器、同一站点地址中的旧账本会自动进入迁移流程；早期没有“攒钱”字段的账本会补上空目标与空存款流水，原有考勤与设置继续保留。换浏览器、换网址或从网页改用手机客户端时，原有 `localStorage` 不会自动跟随；应先在旧环境导出备份，再在新环境导入。升级前主动保留一份旧版 JSON 备份仍是最稳妥的操作。

跨设备恢复可使用 `.wangcai` 文件及创建备份时的口令，或使用该账本对应的恢复密钥。新版备份同时包含加密附件；旧版备份仍可导入，但没有升级后新存入的原件。恢复密钥验证成功后必须设置新口令，并生成新的恢复密钥。旺财不保存恢复密钥、不提供服务器代管；如果口令与恢复密钥都遗失且没有已解锁设备，密文无法恢复。恢复密钥相当于备用钥匙，获得它的人可以解锁账本并重设口令。迁移前的浏览器、系统备份、下载目录或用户自行复制的旧 JSON 文件，无法由应用保证安全擦除。

## 风险边界

- 加密主要保护设备关闭、应用锁定或存储介质被离线读取时的数据。账本解锁后，应用内存中仍有明文；恶意代码若能在解锁期间控制同源页面，可能读取账本或诱导用户输入口令。
- PWA 的网页脚本由当前网站来源提供；若该来源或构建链被攻陷，单靠本机加密不能保护已解锁数据。当前节假日更新是用户主动请求，网络请求只带年份，不包含账本内容。
- Android Keystore、iOS Keychain 生物识别快速解锁尚未接入；当前跨平台保护依赖用户口令。也没有自动闲置锁定，离开应用前请使用“立即锁定账本”。
- JSON/CSV/XLSX 若由用户另行导出为普通文件，文件不受本机密封包保护。分享、邮件或云盘同步这些文件会离开应用控制范围。
- 工作证据 ZIP 包包含明文原件、打卡和工资估算，导出时会提示风险。包内的离线校验页核对哈希链和文件哈希；它只检查包内材料是否与清单一致，不能证明设备时间准确、材料来源可靠或劳动关系存在。持有解锁密钥的用户可以重建本机链；独立时间戳、公证/司法存证未接入。请保留单位通知、工资流水、聊天原件等外部材料作相互印证。
- 附件受浏览器/系统存储配额及清理策略影响；单文件限制 20 MB，当前没有自动云端备份。定期导出完整 `.wangcai` 备份并离线妥善保管；普通 CSV/XLSX 不包含附件。
- 本实现仍使用 `localStorage` 保存单个加密密封包。它适合当前账本规模；大量收支流水后应迁移到加密 IndexedDB 或原生加密数据库，并保留同一密钥封装格式。
