# 旺财 · 理财功能演进建议

## 当前边界

现有“攒钱”页支持目标、存款流水、本月计划进度和年度存款速度估算。它还不是完整收支账本：没有支出、账户余额、转账或取出储蓄的记录。因此“今年已攒”只代表本年录入的存款总额，不能解释为净资产或可支配结余。

设置、考勤与储蓄数据目前保存在本机 `localStorage`；JSON 是完整备份途径。当前 `.xlsx/.csv` 的“储蓄记录”只有存款流水，导入后不能完整重建目标；表格往返应单独补齐并测试。

## 推荐实施顺序

1. **先补数据基础**：增加收入、支出、转账和目标存取的统一流水，区分“工资预估”与“实际到账”。为每笔流水记录日期、金额、类别、账户、备注和稳定 ID；提供编辑、撤销及导入去重。
2. **再做月度规划**：可设置类别预算与固定账单，显示收入－支出－计划储蓄后的可用金额；目标进度按实际净存入计算，并解释估算口径。避免把工资预测自动当成真实收入。
3. **完善备份与可用性**：`.xlsx` 增加目标与流水独立工作表并支持往返；CSV 可分文件导出。增加空状态、筛选、对账提示和手机端大数据量性能测试。扩展数据后评估迁移到 IndexedDB。
4. **最后接入助手**：第一版先用本地确定性规则生成可解释提醒（例如预算超额、目标缺口），每条建议展示所依据的时间段和数字。后续模型只做问答、摘要与情景推演；默认不上传原始流水，用户明确选择数据范围和服务提供方后才分享必要摘要，且不允许助手自动记账、交易或修改设置。

## 界面与组件方向

- 每页保留一个最重要的操作；高频信息前置，低频说明折叠。攒钱页优先显示“本月已存/计划/剩余”和目标进度，历史流水置于目标卡片内。
- 图标按语义分工：铜钱标记金额、元宝标记目标与成果、账册标记记录、钱袋标记计划；图标只作识别辅助，按钮和状态仍保留文字。
- 统一下拉与选择面板的选中态、焦点态及触控区域；弹层在手机小视口内滚动，在平板/桌面不铺满页面。

以上是产品规划，不是投资建议；正式引入 AI 前，仍须对真实数据、隐私边界和推算口径做专门验收。
